# web

The Next.js app for [drawing-agent](../../README.md). Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS 4, React Compiler.

## Running

From the repo root:

```sh
pnpm exec turbo dev --filter=web
```

Or from this directory:

```sh
pnpm dev
```

Then open http://localhost:3000. Editing `app/page.tsx` hot-reloads.

## Scripts

| Command            | What it does                                           |
| ------------------ | ------------------------------------------------------ |
| `pnpm dev`         | Dev server on :3000                                    |
| `pnpm build`       | Production build (type-checks via the local `tsc` CLI) |
| `pnpm start`       | Serve a production build                               |
| `pnpm lint`        | oxlint, configured in `.oxlintrc.json`                 |
| `pnpm check-types` | `next typegen && tsc --noEmit`                         |

`next typegen` has to run before `tsc` — Next generates route types such as `LayoutProps` into `.next/types`, so a standalone `tsc` fails on a clean tree.

Formatting is not per-app: run `pnpm format` at the repo root.
